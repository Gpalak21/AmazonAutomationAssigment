# Amazon Automation Assignment

This project contains Selenium TestNG automation scripts for:

- Galaxy phones (`GalaxyTest.java`)
- iPhone phones (`IphoneTest.java`)

## Features

- Search product on Amazon
- Add to cart
- Extract product price
- Handles multiple windows and waits
- Uses explicit waits, JS scrolling, and stable XPath locators
- TestNG parallel execution support

## How to Run

1. Clone the repository
2. Install Java 23 and Maven
3. Run `mvn test` or use IntelliJ TestNG run configurations
